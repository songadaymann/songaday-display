# Song A Day Display

Ways of looking at Song A Day, the song Jonathan Mann has written and recorded every day since January 1, 2009.

The first display is a rebuilt deep-zoom gallery: every song's artwork in one zoomable mosaic, built with OpenSeadragon. It replaces [song-a-day-gallery](https://github.com/songadaymann/song-a-day-gallery). It moves hosting to Cloudflare, gets faster tiles, and adds each day's new song to the mosaic.

**Status:** just started. See [docs/](docs/) for the plan.

**Live:** not deployed yet.
